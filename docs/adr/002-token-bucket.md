# 002. Два варианта token bucket

`custom` использует монотонные отметки `TimeProvider`. Токены хранятся в целых долях, чтобы частые обращения не теряли дробное пополнение. Пополнение ограничено размером burst. Источник времени подменяется в тестах.

`standard` использует `TokenBucketRateLimiter` без внутренней очереди и фонового таймера. Шлюз вызывает `TryReplenish` перед попыткой списания. В ручном режиме лимитер .NET рассчитывает пополнение пропорционально времени по собственному `Stopwatch`, включая дробные токены. Встроенный режим с таймером здесь не используется. Порядок приёма, FIFO, проксирование и метрики общие для обоих вариантов.
