# 003. Удаление состояния после простоя

Каталог допускает четыре пары клиент–маршрут. Внешнее значение ключа не становится ключом словаря. Перед выдачей состояния шлюз проверяет простаивающие записи и удаляет их, если нет активных владельцев и прошло 30 секунд плюс время восстановления пустой корзины. В стандартном режиме перед удалением шлюз дополнительно проверяет число доступных токенов.

Получение состояния и удаление идут под одним lock. Запрос держит ссылку от списания токена до освобождения слота, включая ожидание в очереди. Поэтому очистка не разделяет один поток на две независимые корзины. Без новых запросов очистка не запускается, объём словаря остаётся ограничен каталогом.
